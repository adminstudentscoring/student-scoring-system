V.Chess 發票 PDF → Excel

大量選取或拖放 PDF；支援一頁兩張發票（左右欄）。Excel 含學員顯示、發票號、課程／時段／日期、老師、金額等欄。
Bulk PDFs; two invoices per page (side-by-side) supported via column + text splitting.

點此選擇 PDF 或將多個 PDF 拖放到此區域 · Click or drop multiple PDFs 

      
    
      
    
      
    
    
    

    
    
      注意 · Notes
    
      僅支援內含可選取文字的 PDF。多頁檔逐頁處理；一頁兩張（左右欄）時會用座標分欄並以 No.: / To: 再切分。掃描圖需 OCR。
    
      Text PDFs. Two invoices per sheet: column split + No.: / To: segments. Scanned PDFs need OCR.
    
      請用本機伺服器開啟本頁（例如 http://localhost:7001/vchess-invoice-pdf-to-xlsx.html），勿用 file://，否則 PDF worker 可能無法載入。
    
      Open via your dev server, not file://, so the PDF.js worker loads correctly.
