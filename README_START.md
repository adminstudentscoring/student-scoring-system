# 快速啟動指南

## 🚀 如何啟動程式？

### 最簡單的方式：

**雙擊 `start.bat` 文件即可！**

---

## 📋 詳細說明：

### 方式 1：雙擊啟動文件（推薦）
1. 在文件夾中找到 `start.bat`
2. 雙擊它
3. 等待幾秒，應用程式就會自動打開

### 方式 2：使用終端
1. 在項目文件夾中打開終端（PowerShell 或 CMD）
2. 輸入：`npm run app`
3. 按 Enter

### 方式 3：創建桌面快捷方式
1. 右鍵點擊 `start.bat`
2. 選擇「發送到」→「桌面（建立捷徑）」
3. 以後可以直接從桌面啟動

---

## ⚠️ 第一次使用前：

確保已經運行過：
```bash
npm install
```

---

## 💡 提示：

- `start.bat` 會顯示一個黑色命令窗口，這是正常的
- 關閉應用程式後，命令窗口也會自動關閉
- 如果不想看到命令窗口，可以使用 `start.vbs`（但看不到錯誤訊息）
